# Data Science

Exercises and practical activities developed throughout the study of Data Science.

## About

This repository contains Jupyter notebooks with exercises covering fundamental concepts and techniques in data science. Each notebook includes the implemented solutions and their respective outputs.

## Structure

The notebooks are organized by chapter and follow the naming convention:

```text id="1g3j8v"
chapter-<number>-exercises.ipynb
```

When a chapter's exercises are divided into multiple parts, the following naming convention is used:

```text id="x6q2fm"
chapter-<number>-exercises-part-1.ipynb
chapter-<number>-exercises-part-2.ipynb
```

For example:

```text id="0n2p5s"
chapter-02-exercises.ipynb
chapter-03-exercises-part-1.ipynb
chapter-03-exercises-part-2.ipynb
chapter-04-exercises.ipynb
```

Chapter 1 contains no exercises and is therefore not included as an exercise notebook.

## Topics

The exercises cover concepts such as:

* Data manipulation
* Lists and dictionaries
* Data analysis
* Data visualization
* Statistical concepts
* Data processing

## Purpose

This repository serves as a record of my exercises, solutions, and progress throughout the study of Data Science.
